# @fomadev/next-advanced-sitemap-cli

[![License: FPL](https://img.shields.io/badge/License-FPL-orange.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)](README.md)

A zero-config, CI-friendly command-line checker for sitemaps generated by [`next-advanced-sitemap`](../next-advanced-sitemap) (or any standards-compliant sitemap). It validates the document schema, sweeps every `<loc>` for broken (404/5xx) responses, and reports file size against the sitemaps.org 50MB limit — designed to fail your build before Google ever sees a broken sitemap.

Part of the `next-advanced-sitemap` ecosystem.

## Usage

No installation required:

```bash
npx @fomadev/next-advanced-sitemap-cli https://example.com/sitemap.xml
```

Or install as a dev dependency for a GitHub Actions / CI step:

```bash
npm install --save-dev @fomadev/next-advanced-sitemap-cli
```

```yaml
# .github/workflows/sitemap-check.yml
- name: Check production sitemap
  run: npx next-advanced-sitemap-check https://example.com/sitemap.xml
```

The process exits with a non-zero status code if the document is malformed or any URL is broken, so it plugs directly into a CI pipeline's pass/fail gate.

### Flags

| Flag | Description |
|---|---|
| `--no-links` | Skip the HTTP `HEAD` broken-link sweep (schema + size check only). |
| `--concurrency=<n>` | Max concurrent `HEAD` requests (default: 10). |
| `--timeout=<ms>` | Per-request timeout in milliseconds (default: 5000). |

### Programmatic API

```typescript
import { checkSitemap } from '@fomadev/next-advanced-sitemap-cli';

const report = await checkSitemap('https://example.com/sitemap.xml');
console.log(report.totalUrls, report.brokenLinks.length);
```
